# Guides

Each guide starts from a goal and ends with working code, tested in CI. Guides assume you know the basics from [Learn](/docs/learn), and link to [Concepts](/docs/concepts) for the why.

| Guide | Goal |
|---|---|
| [Test with testkit](/docs/guides/testing) | Boot a real app in a test, with a fake clock, fakes and a database |
| [Deploy migrations safely](/docs/guides/migrations) | Get a schema change to production, applying only the approved plan |
| [Read from replicas](/docs/guides/replicas) | Spread reads across replicas without reading stale data by accident |
| [Choose a coordination backend](/docs/guides/coordination) | Match the backend to the deploy, and let boot catch a mismatch |

Guides cover what is built. The job system gets its guide when it ships.
