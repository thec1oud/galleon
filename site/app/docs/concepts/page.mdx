# Concepts

Concepts explain how Galleon works and link the [decisions](/docs/decisions) behind it. They describe what is true now. They don't give step-by-step instructions; the [Guides](/docs/guides) do.

The design discussion that came before the decision records is at [commit 0897d74](https://github.com/thec1oud/galleon/tree/0897d74/docs/design). It is history, not a description of Galleon now.
