# Learn

Learn builds one service, a small bookmarks API, in order. Each chapter adds one idea and ends at a checkpoint you can run and test.

| Chapter | You add |
|---|---|
| [1. Your first service](/docs/learn/first-service) | Two operations over HTTP, validation, errors, and a test |
| [2. Configuration and modules](/docs/learn/configuration) | A config section, environment overrides, and dependency injection |
| [3. A database](/docs/learn/database) | PostgreSQL, transactions, and tests against a real database |
| [4. Migrations](/docs/learn/migrations) | A schema the service applies itself, in development and in production |

Every sample on these pages is compiled and tested in Galleon's CI, so the code works as shown.

<Callout>
Later chapters will cover authorization, running several nodes, and read replicas. They aren't written yet.
</Callout>
