# Configuration

Each section is a key of the JSON config file. See [Modules and wiring](/docs/concepts/modules#configuration) for how config is loaded.

A key marked **env** can also be set with the environment variable `<APP>_<SECTION>_<KEY>`, in upper case. The environment wins over the file. A key marked **secret** is redacted in `App.ConfigReport()`.

A `time.Duration` key is a number of nanoseconds in the file, as `encoding/json` reads it, and a string with a unit, such as `30s`, in the environment. The `migrate` section's durations are strings with a unit in both. Defaults are shown with a unit. A blank default is the type's zero value: empty, `false` or `0`.

Sections are listed under the module that reads them: the core's, then those of the modules beside it in this repository.
